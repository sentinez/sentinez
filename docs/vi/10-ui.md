# 10. Web console (UI)

Thư mục [ui/](../../ui/) là workspace **pnpm + turbo** (Node 26, pnpm 12).

```
ui/
├── apps/
│   ├── console/     # sentinez-console — Next.js 16 (App Router), React 19
│   ├── web/         # trang web công khai (Next.js)
│   └── template/    # app mẫu
└── packages/
    ├── ui/          # @sentinez/ui — component dùng chung (shadcn/Tailwind 4)
    ├── proto/       # @sentinez/proto — TypeScript sinh từ proto (ts-proto)
    ├── eslint-config/
    └── tsconfig/
```

Lệnh gốc: `pnpm build | dev | lint | format` (qua turbo). Trong
`apps/console`: `dev` (turbopack), `build`, `start`, `lint`, `typecheck`.

## 10.1 Console

Phụ thuộc chính: `axios`, `@simplewebauthn/browser` (passkey),
`@tanstack/react-table`, `recharts`, `sonner` (toast), `motion`,
`next-themes`, `lucide-react`.

### Route

| Route | Nội dung |
|---|---|
| `/auth`, `/auth/signup` | Đăng nhập / đăng ký bằng mật khẩu |
| `/auth/passkey/login`, `/auth/passkey/register` | Luồng WebAuthn |
| `/tenant` | Chọn tenant |
| `/console` | Trang gốc: `domain`, `member` |
| `/console/[domain]/tenant` | `origin`, `resource` của tenant |
| `/console/[domain]/security` | `sec-rule` (list, `new`, `[id]`), `rulesets`, `rate-limiter` |
| `/console/[domain]/delivery/cdn` | CDN rule |
| `/console/[domain]/analytic` | `activity`, `logs` (`security/sec-rule`, `security/rulesets`) |

Thành phần đáng chú ý:
`app/console/[domain]/security/components/query-builder.tsx` (trình dựng
expression cho SecRule) và `sec-rule-fields.tsx`.

### Gọi API

- `lib/api/{iam,security,tenant}` dùng axios gọi tới `/api`
  (`lib/api/base.ts`). Route Next.js `app/api/[...path]` chuyển tiếp request
  tới `API_BASE_PATH` chỉ có ở server (mặc định `http://localhost:8080`).
- `lib/api/base.ts` đăng ký một axios request interceptor: mọi request tới
  `/api/...` mang `Authorization: Bearer <token>`, với token mà form đăng
  nhập lưu trong `localStorage` (`SENTINEZ_ACCESS_TOKEN_KEY`). Khi chưa đăng
  nhập thì không gửi header. Module API có được điều này nhờ import
  `API_BASE_PATH` từ file đó. Token bị từ chối hoặc hết hạn chưa được xử lý
  tập trung (chưa chuyển về trang đăng nhập).
- `lib/session.ts`: `isSignedIn()` đúng khi `exp` của token đã lưu còn ở
  tương lai (token hết hạn bị xoá); `homePath()` là `/console/domain` khi đã
  lưu tenant id (`SENTINEZ_TENANT_KEY`), ngược lại là `/tenant`. Form đăng
  nhập chuyển tới `homePath()`. `redirectFor(pathname)` giữ các quy tắc
  route: người đã đăng nhập vào `/auth/...` được đưa tới `homePath()`;
  `/tenant` và `/console/...` khi không có token hợp lệ được đưa về `/auth`;
  `/console/domain/...` khi chưa có tenant id được đưa về `/tenant`.
- `components/session-redirect.tsx` áp dụng các quy tắc đó:
  `SessionRedirect` ở root layout bắt đầu chuyển trang ngay khi splash
  (`LoadingEffect`) còn hiện, và `RouteGuard` (layout auth, tenant và console)
  hiện spinner thay cho trang mà người dùng đang rời đi.
- Mọi hàm API dùng kiểu sinh từ `api/proto/sentinez/apps/<domain>/v1`
  (`@sentinez/proto/sentinez/apps/<domain>/v1/...`): nhận `XxxRequest`, trả
  `XxxResponse`, ví dụ `updateSecRule({ id, secRule, updateMask })`. Body tạo
  bằng `XxxRequest.toJSON`, response parse bằng `XxxResponse.fromJSON`, nên
  enum, int64, `Timestamp`, `FieldMask` và `bytes` do code sinh tự chuyển đổi;
  không có interface wire viết tay.
- Query param của GET lấy từ `toQuery(XxxRequest.toJSON(req))` trong
  `lib/api/pages.ts` (field lồng nhau thành `page.index`, field lặp gửi dạng
  `ids=a&ids=b`).
- Các trang dùng trực tiếp model proto (`SecRule`, `RateLimit`, `Resource`);
  phần map form <-> model nằm trong `components/` của từng mục
  (`secRuleFormOf` / `secRuleOf`, `rateLimitFormOf` / `rateLimitOf`,
  `resourceFormOf` / `resourceOf`).
- `NEXT_PUBLIC_USE_SAMPLE=true` trả dữ liệu mẫu khi API lỗi (tiện phát triển
  UI không cần backend).
- `hooks/use-api.ts`: hook `useApi(fn, ...args)` quản lý `data/isLoading/
  error/refresh`, huỷ request bằng `AbortController`, hiển thị toast lỗi qua
  `handleStatusError`. Truyền `null` làm tham số đầu để tạm không gọi.
- Token và thông tin user lưu ở localStorage với key
  `sentinez.ui.accessToken`, `sentinez.ui.refreshToken`, `sentinez.ui.user`.

## 10.2 Kiểu dữ liệu chung với backend

`@sentinez/proto` được sinh từ `api/proto` bằng `buf generate`
(`useOptionals=messages`, `outputJsonMethods=true`, không sinh service). Khi
đổi proto, chạy lại `cd api && buf generate` rồi build package proto để UI
nhận kiểu mới.
