# 7. Control plane

The `github.com/sentinez/controlplane` module
([staging/src/github.com/sentinez/controlplane](../staging/src/github.com/sentinez/controlplane/))
holds the domain services. Every domain follows the same layout:

```
<domain>/v1/
├── <domain>.go     # gRPC module: NewService(ctx, conf) + Start() serving over bufconn
├── factory/        # NewDefaultHandler / NewDefaultService: build repo → service → handler
├── handler/        # implements <X>ServiceServer, permission checks, logging
├── service/        # business logic
└── repos/<name>/   # PostgreSQL access (IXxx interface + struct)
```

Scaffolding for each layer lives in `.agent/skills/` (`create-service`,
`create-handler`, `create-repo`, `create-factory`, `create-module`).

## 7.1 Storage layer (`core/storage/dbx`)

[core/storage/dbx](../staging/src/github.com/sentinez/core/storage/dbx/):

- `dbx.Database[T]`: `Insert`, `Select`, `Delete`, `Total`, `Table`, plus
  `Exec`, `Query`, `CollectRows`, `CollectOneRow` taking a `query.Query`
  (squirrel's `ToSql()` interface).
- `postgres.New[T](ctx, conf, WithTable(name), WithColumns(cols))`:
  - The real table name is `<mode>.sentinez.<name>` with `.` replaced by `_`,
    e.g. `dev_sentinez_iam_users`; it must match
    `^(dev|sandbox|prod)_sentinez_[a-z]+(_[a-z]+)*$`.
  - Creates the table (`id TEXT PK, created_at, updated_at`) and adds missing
    columns — it **never drops or retypes columns**.
  - Uses one global `pgxpool.Pool` from `SENZ_POSTGRES_URI`.
- Helpers: `SelectBuilder` (+ paging `LIMIT/OFFSET ORDER BY created_at DESC`
  when `page.index` and `page.size` are > 0), `InsertBuilder`
  (`RETURNING id`), `UpdateBuilder` (sets `updated_at` automatically).
- Transactions: `postgres.NewTX(conf).Begin(ctx)` → `*TxSession`;
  `postgres.WithTx(ss, db)` returns a `Database[T]` bound to the
  transaction; repositories expose `WithTX(ss)`.
- Record IDs: `rand.NewID(table.NewPrimaryKey(name))` =
  `senz.<name>.<uuid>`.

Table names ([core/common/tables](../staging/src/github.com/sentinez/core/common/tables/tables.go)):
`iam.users`, `iam.accounts`, `tenant.resources`, `analytic.activities`,
`security.sec_rules`.

Column-name constants (`User_Email`, `SecRule_Expr`, ...) are generated by
`protoc-gen-go-senz` for messages with the
`x_message.database_model = true` option.

## 7.2 Authentication & authorization

[controlplane/pkg](../staging/src/github.com/sentinez/controlplane/pkg/):

| Package | Purpose |
|---|---|
| `crypto` | `TokenGenerator(*typepb.Context)` signs an HS256 JWT with secret = base64-decode(`SENZ_SECRET_KEY`); claim `auth` = `Context.String()` (prototext), `exp`. `BearerTokenVerifier` strips the `Bearer ` prefix, verifies the HMAC and parses the `Context` back. `HashPassword`/`CheckPasswordHash` use bcrypt |
| `headers` | `GetAuth(ctx)` reads the `Authorization` metadata and verifies it → `Auth{*typepb.Context}`; `Auth.Check(method)` calls `perms.Allow` |
| `passkey` | `NewWebAuthn(conf)` (RP = `core.Name`, RPID = `SENZ_HOSTNAME`, origin = `SENZ_CLIENT_ORIGIN`); in-memory `Store` (WebAuthn sessions + pending accounts) |

`typepb.Context` = `{name, expire_at, user_id, control_plane}`; JWTs expire
after 1 hour.

Authorization is based on the **control plane** (`PORTAL` / `ADMIN`):

- Each RPC may declare `option (sentinez.types.v1.x_method) = {ignore |
  control_planes: [...]}`; codegen produces `Get<Service><Method>()`.
- `perms.Allow(method, cp)` allows access if the method is nil, `ignore` is
  set, the list is empty, or `cp` is in the list.
- Handlers must **call** `headers.GetAuth` + `Check` **themselves** — today
  only `IAM.ListAccounts` and `Analytic.ListActivities` do. There is no shared
  gRPC interceptor.

## 7.3 IAM

Protos: [apps/iam/v1](../api/proto/sentinez/apps/iam/v1/). Tables:
`iam.users` (`id, email, full_name, control_plane`) and `iam.accounts`
(`id, email, username, password_hash, credentials TEXT[], user_id, provider,
provider_user_id`). A `User` can have several `Account`s.

| RPC | REST | Behavior |
|---|---|---|
| `Login` | `PUT /iam/login` | If username = `SENZ_ADMIN_USERNAME`: compares the password with `SENZ_ADMIN_PASSWORD` and issues an ADMIN token (`user_id = sentinez.admin`). Otherwise: finds the account by username/email, bcrypt check, loads the user, issues a PORTAL token |
| `CreateAccount` | `POST /iam/account` | Checks for duplicate username/email, then in one transaction creates a `User` (PORTAL) + `Account` (bcrypt) |
| `CreateUser` | — (gRPC only) | Creates a `User` if the email is not taken |
| `GetUser` | `GET /iam/user` | By `id` or `email` |
| `ListUsers` | `GET /iam/users` | Filters `ids`, `emails`, paging |
| `UpdateUser` | — | Updates `full_name`, `email` |
| `DeleteUser` | `DELETE /iam/user/{id}` | Deletes a user |
| `ListAccounts` | `GET /iam/accounts` | Requires a token; filters `ids/emails/user_ids/usernames` |
| `Status` | `GET /iam/status` | Calls Greeter.Status over bufconn, returns the `Context` from the token (if any) |
| `PasskeyRegisterChallenge` | `GET /iam/passkey/register/challenge` | Fails if the username/email already exists; creates a pending in-memory account, `BeginRegistration`, saves the session, returns `options` + `session_id` |
| `PasskeyRegisterVerify` | `POST /iam/passkey/register/verify` | Loads session + pending account, creates the real account (random password) if missing, `CreateCredential`, stores the credential JSON in `credentials` |
| `PasskeyLoginChallenge` | `GET /iam/passkey/login/challenge` | `BeginLogin` for the account, saves the session |
| `PasskeyLoginVerify` | `PUT /iam/passkey/login/verify` | `ValidateLogin`, updates the credential (sign count), issues a token (ADMIN if username is `admin`) |

`AccountX` wraps `iampb.Account` to implement `webauthn.User` (WebAuthn ID =
email).

## 7.4 Tenant

Protos: [apps/tenant/v1](../api/proto/sentinez/apps/tenant/v1/). Table
`tenant.resources` (`id, resource_setting BYTEA, resource_name,
resource_domain, plan, status`). `resource_setting` is an `edgepb.Setting`
stored as binary protobuf — i.e. the tenant's edge configuration.

| RPC | REST | Notes |
|---|---|---|
| `ListResource` | `GET /tenant/resources` | Filters `status`, `plan`, `resource_name`, `resource_domain` |
| `CreateResource` | `POST /tenant/resource` | Empty `resource_setting` → default `Setting{}` |
| `UpdateResource` | `PUT /tenant/resource` | Updates domain/name/status/plan (not the setting) |
| `DeleteResource` | `DELETE /tenant/resource` | |
| `GetResource` | `GET /tenant/resource` | `default=true` → replaces the setting with the default |
| `GetResourceByDomain` | `GET /tenant/resource/{resource_domain}` | Returns the first record matching the domain |
| `Status` | `GET /tenant/status` | |

These RPCs declare `control_planes: [PORTAL, ADMIN]` but the handler does not
check tokens yet.

## 7.5 Security

Protos: [apps/security/v1](../api/proto/sentinez/apps/security/v1/). Table
`security.sec_rules` (`id, name, description, expr JSONB, status, priority,
action JSONB`).

| RPC | REST |
|---|---|
| `CreateSecRule` | `POST /security/secrule` |
| `GetSecRule` | `GET /security/secrule/{id}` |
| `UpdateSecRule` | `PUT /security/secrule/{id}` |
| `DeleteSecRule` | `DELETE /security/secrule/{id}` |
| `ListSecRules` | `GET /security/secrules` (filter `ids`, paging) |
| `Status` | `GET /security/status` |

The service requires `sec_rule` on create/update; `UpdateSecRule` loads the
record, overwrites fields from the request and calls the repo's `Update`.
Rules stored here are **not pushed to the edge yet**.

## 7.6 Analytic, Greeter, CentralData

| Domain | Status |
|---|---|
| Analytic | `ListActivities` (`GET /analytic/activities`, requires a token) over table `analytic.activities` (`id, resource_id, unique_visitor INTEGER[]`). Not registered in the apiserver |
| Greeter | Sample service: `SayHello` (`GET /greeter/say?name=`) replies with the current time; `Status`. Has its own `szgreeter` binary and also runs in-process in the apiserver |
| CentralData | Only `Status`; the `szcentraldata` binary has no `main` body |

## 7.7 Error codes

[shared/errorx](../staging/src/github.com/sentinez/shared/errorx/errors.go)
provides gRPC statuses formatted as `SENZ-<code>: <ERRORS_...>` and
`StatusXxxF(format, ...)` helpers (`NotFound`, `Unauthorized`, `Forbidden`,
`InvalidData`/`InvalidArgument`, `AlreadyExists`, `Internal`,
`Unimplemented`). The sentinels `ErrNotFound`, `ErrInvalidData`,
`ErrUnimplemented` are mapped to HTTP by the gateway. `IsNoRows(err)`
detects `pgx.ErrNoRows`.
